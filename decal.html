How do I get an Open Cloud API key?
  1. Open Creator Hub → API Keys and click Create API Key.
  2. Name it, e.g. LNZ Uploader.
  3. Under Access Permissions, add the Assets API and tick Read and Write.
  4. Under Accepted IP Addresses, add 0.0.0.0/0.
  5. Save, copy the key and paste it above.
